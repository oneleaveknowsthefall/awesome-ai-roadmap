# FDE · 基础与交付方法

本模块用一章讨论 Forward Deployed Engineering 的工作方式。读完后应能拿一个具体需求，解释从接手到交付的判断，而不是只列技术栈。

## 章节目录

1. [第一章：Forward Deployed Engineering：从业务问题到可复用生产系统](01-forward-deployed-engineering.md)

## 面试准备怎么读

先读 1.3—1.7 节，练习把客户的一句话还原成任务、证据、权限和退出条件。再看 1.10 节的公开实践：哪些是原文披露，哪些只是厂商目标，哪些本轮未能重新读取。

1.11 节是**虚构的工业备件订单异常助手**，从模糊需求推演到样例对话、验收账本、失败路径、灰度回滚与收益测算，不需要搭建应用。公司、数据和数字均是假设或编写的模拟材料，不代表 Polo Li 的真实经历；模拟面试时应主动说明这一点。最后用 1.12 节的追问检查自己的取舍是否站得住。
