# Agent · 记忆与上下文

覆盖记忆分类、长短期存储、召回使用与上下文压缩。

建议先读第七章区分记忆的作用域、内容与存储，再读第八章的写入一致性和权限控制，最后用第十章检查压缩后还能否恢复状态、找到证据。持久化解决“数据还在不在”，检索解决“找不找得到”，Context 构建解决“这轮模型实际看到了什么”；三者不能互相替代。

框架与 API 的持久化、缓存和删除行为并不完全相同，阅读示例时应同时确认章内说明的版本与适用范围。
